Eager Loading vs Lazy Loading

One of the most critical aspects of using Eloquent efficiently is understanding the difference between lazy and eager loading. Lazy loading retrieves relationships only when they are accessed, leading to the infamous N+1 query problem.

Lazy Loading Example (Bad) 
$books = Book::all();

foreach ($books as $book) {
    echo $book->author->name; // N+1 Query Problem
}

Eager loading solves this by fetching the relationships upfront using a single `IN` query.

Eager Loading Example (Good) 
$books = Book::with('author')->get();

foreach ($books as $book) {
    echo $book->author->name; // Only 2 queries total
}
